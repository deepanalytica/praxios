# PRAXIOS Agent Protocol

Este repositorio no se opera como un proyecto de software aislado. Es parte de PRAXIOS OS.

## Antes de trabajar

1. Lee `praxios/state/STATE_BRIEF.md`.
2. Lee `docs/CONSTITUTION.md`.
3. Identifica proyecto, misión, decisión vigente y restricciones.
4. Reutiliza capacidades existentes antes de proponer un proyecto nuevo.
5. Distingue hechos, evidencia, hipótesis y decisiones.

## Durante el trabajo

- vincula cambios a una misión y métrica;
- registra riesgos o contradicciones que puedan afectar decisiones anteriores;
- si encuentras oportunidad comercial, describe comprador, problema, oferta, time-to-cash y test mínimo;
- evita actividad sin resultado verificable;
- no comprometas pagos, contratos ni acciones irreversibles sin aprobación humana.

## Antes de finalizar una sesión material

Crea exactamente un archivo JSON bajo `praxios/harvest/` siguiendo `docs/SESSION_PROTOCOL.md`.

La cosecha debe registrar lo que cambió en el sistema: ideas útiles, decisiones explícitas, tareas, riesgos, oportunidades, evidencia, recursos y hallazgos.

No inventes decisiones del usuario.

## Objetivo

Cada sesión debe aumentar el patrimonio institucional de PRAXIOS. El valor no es la conversación; es el estado reutilizable que queda después.
