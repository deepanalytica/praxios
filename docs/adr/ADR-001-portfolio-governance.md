# ADR-001 — Gobierno de cartera antes que multiagentes autónomos

Estado: Accepted

## Contexto
Es fácil construir agentes que conversan entre sí, pero esa arquitectura puede producir actividad sin valor económico.

## Decisión
PRAXIOS se diseña primero como sistema de portfolio governance. Cada iniciativa debe poder terminar en TEST, BUILD, SCALE, HOLD o KILL.

El AI CEO es un asignador de capital, no un chatbot coordinador.

## Consecuencias
- menor autonomía teatral;
- mayor trazabilidad;
- prioridades comparables;
- posibilidad de cerrar proyectos;
- toda automatización futura se conecta a un sistema de decisiones ya existente.
